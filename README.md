# Webtech-Exp6
Aim :
To create web pages using various timer functions, events and objects in JavaScript.

Description:
This experiment demonstrates Timing Events, Date Object, and Classes and Objects in JavaScript. It uses setTimeout(), setInterval(), clearInterval(), Date methods, and classes to perform time-based operations and create objects.


Procedure:

1.	Open Visual Studio Code and create an HTML file named index.html.
2.	Create the basic HTML structure using the required tags.
3.	Add JavaScript code inside the <script> tag.
4.	Use setTimeout() to execute a function after a specified time.
5.	Use setInterval() to execute a function repeatedly at regular intervals.
6.	Use clearInterval() to stop the repeated execution.
7.	Create a Date object using new Date().
8.	Use Date methods to display the current date, time, year, and month.
9.	Create a JavaScript class using the class keyword.
10.	Define a constructor and methods inside the class.
11.	Create objects using the new keyword and access their properties and methods.
